# juego-serpiente-UIDE
Este proyecto es la segunda parte de mi trabajo de Lógica de Programación en la UIDE, donde estoy desarrollando el clásico juego de la serpiente (Snake). En la entrega anterior definí los casos de uso (como mover la serpiente, comer, sumar puntos y el Game Over) y la arquitectura en tres capas: la interfaz visual, la lógica del juego y el manejo de datos en memoria.
Para esta etapa, organicé el repositorio en GitHub, diseñé los diagramas de flujo para estructurar cómo piensa el programa paso a paso y armé la primera versión funcional del código. El juego ya abre su ventana, responde a los controles del teclado, genera las frutas de forma aleatoria, suma puntos y detecta cuando pierdes al chocar contra las paredes o contra el propio cuerpo de la serpiente.
